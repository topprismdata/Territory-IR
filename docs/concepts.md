# 核心概念与指标

## 1. 统一铺盖 U（Tessellation）

**原子单元片**的来源：把城市的四级路网父地块（如广州 2675 个）按区划街道面
（174 个）做几何切分，得到互不重叠的最小单元片集合（广州 6261 片）。

每片携带四元组：

```
U[k] = (geometry, 主街道标签, 所在街道面, 父地块号)
```

主街道标签与所在街道面可能不同（街道面互相重叠的边界争议区），
条款词法 `slice` 利用这一点表达「A 街道中位于 B 街道界内的部分」。

片是**原子的**：所有生成、描述、调整都是片归属变更，永不切割片几何。

## 2. 真值片 T（Truth）

手绘围栏 → 真值片的选择规则（`compile_fence`）：

```
片 ∩ 围栏 面积 ≥ 50% × 片面积        （片大部分在围栏内）
或 片 ∩ 围栏 面积 ≥ 30% × 围栏面积    （围栏大部分被该片覆盖）
```

T 就是「手绘围栏的真实单元组合」——它是后续一切验证的**答案卷**。

## 3. 条款词法（Clause Vocabulary）

| 类型 | 语法示例 | 解析规则 |
|---|---|---|
| `slice` | `联和街道(限凤凰街道内)` | 主街道=联和 且 所在街道面=凤凰 的片 |
| `feat` | `联和街道沿天慧路(限新塘街道内)` | 街道 ∩ 地物缓冲区（路 100m / 河 100m） |
| `block` | `前进街道` | 街道全域 |
| `pieces` | `P#1473` | 直接片指针（内部兜底，非语言） |
| `band` | `东至联和街道—新塘街道界` | 行政界/街道界剩余带（返回空片集，几何单独附加） |

词表 `vocab()` 一次性枚举全部语言条款 + P# 指针；`clause_pieces(clause)`
是唯一解析入口——**条款 → 片集合**。

## 4. 贪心合成（synth）

真值片 T → 条款列表的贪心选择，代价键：

```
key = (超选片数, -新增覆盖, -地物等级)
```

优先选超选少的词；同等覆盖下选主干道（`motorway` > `residential`）。
循环直到覆盖 T 全部。

## 5. 人话描述（verbalize）

条款 → 业务可读短语：

- 街道全域 → `凤凰街道`
- 街道沿路 → `龙洞街道沿渔东路`
- 界带 → `东至联和街道—新塘街道界`
- P# 指针不进人话（它们不是语言）

## 6. 指标

### J（engine_J）—— 描述复现保真度

```
J = |S∩T| / |S∪T|
```

S = 条款回放片集合。**J 是本系统的核心指标**：
- J=1.0：描述无损编码了围栏的片组合
- over（S 有 T 无）= 多说的；miss（T 有 S 无）= 漏说的

### 纯语言 J

去掉 `pieces`（P# 指针）后重算的 J，衡量「纯靠说话能圈回多少」。
指针占比高的领地（碎片型/enclave 型）纯语言 J 会显著下降——这是词表
表达力的边界，不是 bug。

### IoU / 覆盖（几何）

- `iou`：重演片并集 vs 手绘多边形（更严：受片粒度限制）
- `cover`：围栏被片并集覆盖的百分比

手绘边界切在片中间时 IoU 必然 < 1——这是量化精度的物理极限。

## 7. 语义构面（semantics）

自然语言 → 片集合的 IR 路径（新建合同）：

```
areas（街道/区名）  → block 片并集（底池）
bounds（方向界路）  → 沿路侧向过滤（北界=保留路南的片）
center（兜底）      → 无街道时取中心 6km 半径
```

沿路分堆（`split_pieces_by_road`）：每片质心找最近路段的方向向量，
法向指向目标侧，点积判侧。**只分堆，不切割**。

## 8. 调整（Adjust）= 片归属变更

「把 A 的东部划给 B」：

```
东部半区 → A 的 S 片中质心在整体质心以东的片
划转     → A.S -= moved; B.S |= moved
围栏     → A 围栏 ∩ 剩余片（清空则无围栏）；B 围栏 ∪ moved 并集
```

无门店的经销商同样可调（门店是派生效果层，只出统计信号，永不作为
失败条件）。半区/街道/区选择器见 `semantics.select_pieces`。
